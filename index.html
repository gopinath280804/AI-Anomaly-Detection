Project Overview

G-CAD presents an AI-driven framework for detecting anomalies in user and network behavior. Unlike traditional systems, it focuses on behavioral analysis and dynamic risk scoring — identifying unusual activities, assigning risk levels, and ensuring secure, tamper-proof logging of events.
